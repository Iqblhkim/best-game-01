# VOIDLIGHT — Neon Arena

A complete, original neon twin-stick arena shooter built for make.fun's
"Make the best game" bounty ($1,000 in USDC).

Survive 10 waves of glowing enemies and clear Wave 10 to win. Score with a
combo multiplier (x1–x5), wave-clear bonuses, and a best score saved locally.
Four enemy kinds (chaser, weaver, splitter, shooter), power-ups (shield,
rapid fire, spread shot, void bomb), parallax starfield, particle explosions,
and synthesised WebAudio sound effects — all procedural, zero assets, zero
network requests. Plays offline in a desktop browser from its own files.

## Play

Open `game/index.html` in desktop Chrome, or serve it locally:

```
node serve.ts
```

then open http://localhost:8080.

## Controls

- WASD / arrows — move
- Mouse — aim, hold click / Space — fire
- Enter / click — start & restart
- P — pause, R — restart, M — mute
